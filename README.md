# HieuSubViP

Website bán like/sub tĩnh (HTML/CSS/JS) deploy Netlify.

## Dữ liệu người dùng
Tất cả số dư, đơn hàng, nạp tiền, dịch vụ admin, thông báo được lưu trong **localStorage** trình duyệt.
- Cập nhật file HTML/CSS/JS **không xóa** dữ liệu cũ.
- Chỉ mất khi user xóa cache trình duyệt hoặc bấm "Xóa dữ liệu demo" trong Admin.
